I Assumed as below: Volume Tank A (VTA) = 4 x 2 x 2 x 22 : 7 = 50.28 inch3 Volume Tank B (VTB) = 4 x 1 x 1 x 22 : 7 = 12.57 Volume pressure tank A (VPA) = 50.28 x 100 PSI = 5,028 Volume pressure tank B (VPB) = 12.57 x 50 PSI = 628.6 To calculate joint pressure (not include pipe) = (VPA+VPB) / (VTA+VTB) = (5,028 + 628.6 ) / (50.28 + 12.57) = 5,656.6 / 62.85 = 90 PSI Please correct me if above calculation are wrong.
