Introduction Multi Expression Programming (MEP) [5, 6] is a new and very efficient technique that may be used for solving difficult real-world problems. A unique feature of MEP is its ability of storing multiple solutions in a single chromosome [5]. As shown in [5], this feature does not increase the complexity of the decoding process when compared to other Genetic Programming (GP) variants that stores a single solution in a chromosome. MEP technique has been used [5] for solving symbolic regression problems. Numerical experiments proved that MEP significantly outperforms similar techniques. In this paper, MEP is used for solving even-parity problems. According to [3] the Boolean even-parity functions appear to be the most difficult Boolean functions to detect via a blind random search. Due to this reason the ability of the evolutionary algorithms of performing an efficient search in the space of solutions can be tested using this problem as a benchmark.
