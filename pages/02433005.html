Animated gifs and avatars

· archived # 2,433,005
I was just wondering why animated avatars aren't allowed? I have one which is resized to 80x80 and is 9kB in size so no additional bandwidth load is required. I mean if somebody simply forgot to turn on this function of vB forum it's done like this Admin CP --> Usergroups --> Usergroup Manager Then choose Go beside the Usergroup you wish to be able to upload animated gif's and change Can Upload Animated GIF to Yes. You can do the same for profile pictures if you want. The option is there for Avatars and Profile Pictures. Be sure to choose the right one It's not so important but small details can sometimes make a man happy.
