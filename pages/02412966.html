The A.R.D.A. project A dvanced R educed D rag A ircraft By Jean-Louis Naudin created on March 25, 1999 - JLN Labs - Last update April 10, 1999 The purpose of this project is to build a light weight flying aircraft which uses an EHD ( E lectro- H ydro D ynamics) apparatus based on the T.T. Brown effect for reducing significantly the air drag on the wings during the fly, this will reduce the power consumption of the engines and also will improve the flight performances. I have experimented successfuly the T.T.Brown effect in a previous experiment with two rotating wings . The ARDA ( A dvanced R educed D rag A ircraft) Project is composed of two main phases : Phase One : Build and Test in real flight a light weight flying wing propelled by electrical engines. This will validate the choice of the aerodynamical model, the avionic and also the control systems. (I used a SlowFlyer Kit sold by Watt-Age Electrics, 18480 Bandilier Circle - Fountain Vallet, CA.92708.) Phase Two : Build a new model based on the previous prototype which will use the EHD systems.
