Permutation Rotations Bassam Abdul-Baki March 23, 2025 Abstract In this paper, we discuss certain properties of permutation rotations on each other. Definition Let S(N) be the set of all permutations for the integers 1 to N. Define the sum of two permutations (i.e., x + y) as the permutation y performed on x in S; or in simple terms, for every element in x (i.e. x[j] is the j th element of x, where 1 ≤ j ≤ N), find its current position in y (i.e., y[j]) and move it to the new position assigned by the value of the jth element of y (i.e., (x + y)[j] = x[y[j]]). Thus, x + y = (x[y[1]], …, x[y[N]]). Note: • The positions are counted from 1 to N, while the permutation positions are counted from 0 to N! − 1. • The set x can be a group of anything since it is the y that is performing the permutation upon it. Example For N = 4, let x = (a, b, c, d) and y = (2, 1, 4, 3). Then x + y = (b, a, d, c). Table 1 – S(4) defines the ordered permutation number (n) of all permutations of the set S when N = 4.
