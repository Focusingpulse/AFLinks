The old BBS files were written in Dos based Professional Write and viewed, edited and organized using XTreePro. I always loved how easy XTreePro was to load and run as any text file could be edited in a flash. They of course couldn't leave a good thing alone so made XTreeGold and the company went out of business. XTreePro will still run in DOS but isn't Windows compatible. When the BBS archives were all placed online as avaliable at; http://216.60.190.54/archive.htm I put in a note that XTreePro was no longer available but recently I was told of a workalike version called ZTREE which ran with Windows. They offer a 30 day free trial so I have been running it without flaw now for about 20 days and plan to purchase it for the $30.00. It is so cool to be able to open any of the BBS files or HTML files and edit them so quickly. The reason I bring it up here is that it is PERFECT for viewing or editing the old BBS files as they are unzipped (if you choose to download them) and ZTREE is both quick and easy to use. Lately I have also been using the ZTREE edit function to modify HTML files on the fly and using Netscape to monitor how they appear when run. I plan to send Kim (the guy at ZTREE) a note asking if he can add a run HTML function for this purpose. For text files like those in the BBS archives and a whole lot of other cool options, give ZTREE a shot; http://www.ztree.com/ -- Jerry Wayne Decker - jdecker@keelynet.com http://www.keelynet.com from an Art to a Science Voice : (214)324-874
