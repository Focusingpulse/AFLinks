Overview On the Lorentz Invariance of Maxwell's Equations is a ten-page paper by Vesselin C Noninski , posted to the PhilSci-Archive at the University of Pittsburgh in 2003. Its abstract states the claim in one sentence: "It is shown that, contrary to existing opinion, Maxwell's equations are not invariant in form under Lorentz transformations." The argument works entirely within Einstein's 1905 paper, using its notation — ( X , Y , Z ) for the electric field components and ( L , M , N ) for the magnetic, with primes for the moving frame and β = (1 − v ²/ c ²)^(−1/2). Noninski takes the transformed Maxwell–Hertz equations for empty space as Einstein writes them, in which the field combinations β( Y − ( v / c ) N ) and β( N − ( v / c ) Y ) appear, and asks what these reduce to when expanded consistently in powers of v / c . His key move rests on an observation about magnitudes. Expanding β to second order gives β ≈ 1 + v ²/2 c ², so β( Y − ( v / c ) N ) = Y − ( v / c ) N + ( v ²/2 c ²) Y + …. Noninski then argues, citing his own earlier paper, that the component N "implicitly contains a velocity, u , over c term", and that since "nothing restricts velocity, u , from being comparable to velocity v ", the term ( v / c ) N is itself of second order in v / c . Consistency then requires dropping it alongside the ( v ²/2 c ²) Y term, giving his equation (1): β( Y − ( v / c ) N ) = Y . Applying the same reasoning to the other combination, he finds that the third-order term drops but the first-order one survives, giving his equation (2): β( N − ( v / c ) Y ) = N − ( v / c ) Y .
