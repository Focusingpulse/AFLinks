The universal profinitization of a topological space Pierre-Yves Gaillard To a topological space X we attach in two equivalent ways a profinite space X 0 and a continuous map φ : X → X 0 such that, for any continuous map f : X → Y , where Y is a profinite space, there is a unique continuous map f 0 : X 0 → Y such that f 0 ◦ φ = f . Let X be a topological space. Let X 0 be a profinite space. The purpose of this text is to prove that such a pair does exist, and to define it in two (necessarily equivalent) ways. The first method is to use the Stone-Čech compactification β(X ) of X , and to set X 0 := β(X )/∼ where x1 ∼ x2 if and only if x1 and x2 are in the same connected component. The only thing to verify is that β(X )/∼ is a profinite space. To prove this, the only slightly delicate point is to check that β(X )/∼ is Hausdor , but this follows from Corollary 5.7.11 in [1].
