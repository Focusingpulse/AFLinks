Герловин И. Л. | Обсуждение Теории Фундаментального поля (ТФП)

1 А.М. Протодьяконов ПРОГРАММА РАСЧЕТА ПАРАМЕТРОВ МИКРОЧАСТИЦ НА ОСНОВЕ ТЕОРИИ ФУНДАМЕНТАЛЬНОГО ПОЛЯ И.Л. ГЕРЛОВИНА Целью настоящей публикации является представление разработанной программы и результатов машинного расчета на персональном компьютере по этой программе параметров микрочастиц по формулам, выведенным в Теории Фундаментального Поля, разработанной талантливым советским физиком-теоретиком И.Л. Герловиным в 1960-х – 1980-х годах. Программа расчёта параметров микрочастиц разработана по формулам Периодического Закона Микрочастиц (ПЗМ), являющегося составной частью разработанной И.Л. Герловиным Теории Фундаментального Поля (ТФП). При составлении программы по опубликованным в литературе ТФП [1-6] формулам был применен пакет программ МАТЛАБ – интерактивной системы выполнения научных и инженерных расчетов с массивами данных на персональных компьютерах. Настоящая публикация представляет собой разработанный комплект m.файлов (с комментариями) пакета программ МАТЛАБ для машинного расчета параметров 1, 2 и 3 рядов микрочастиц основных состояний (1-4) по формулам [5, табл.16.1] c исправлением опечаток и ошибок путем их сравнения с опубликованными ранее [2 - 4]. Примененные в разработанных m.файлах обозначения сведены в прилагаемой таблице. Для используемых в расчетах вычисленных параметров оптимальных частиц «OP» (протона и электрона) применены соответствующие индексы «p, e». Файлы публикуются в текстовом редакторе PDF. Приведены таблицы (PDF) результатов выполненных по разработанной программе расчетов внутренних параметров микрочастиц и, в качестве примера, внешних параметров выбранных по 1-2 микрочастицам ПЗМ для каждого ряда с целью их сравнения с опубликованными И.Л. Герловиным результатами [5,6]. Для самостоятельного выполнения расчетов по представленному комплекту файлов они должны быть конвертированы в m.файлы и использованы версии программ МАТЛАБ, начиная с 6-6.1 и выше.
