GTM2026-main044 Cost of cooperation in finite stochastic games Maria Bykova1 , Elena Parilina 1 St Petersburg University masha.bykova253@gmail.com We consider a class of cooperative stochastic games with random duration and address the problem of cooperation sustainability using an axiomatic approach. Within this framework, we define a set of desirable properties and then construct a payment scheme that satisfies them — a set of functions that redistribute the players’ payoffs over time. In existing schemes for stochastic games, some scenarios are not feasible due to insufficient savings to cover deficits at some stages. In our work we calculate the cost of cooperation — the minimum additional payment required to achieve feasibility.
