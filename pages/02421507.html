Power units based on dislocation site techniques Patent Patentnummer US8603405B2 Bezeichnung Power units based on dislocation site techniques Anmelder NPL Associates Erfinder George H. Miley Xiaoling Yang Anmeldetag 13.05.2013 Veröffentlichungstag 07.11.2013 Erteilungstag 10.12.2013 „ Ein verteiltes Energiesystem enthält einen gasbeladenen Wärmeerzeuger, der Wärmeenergie erzeugen kann. Das System enthält eine Gasquelle zum Bereitstellen eines oder mehrerer Isotope von Wasserstoff, eine Vielzahl von metallischen Mikrostrukturen, eine Gasladekammer, die die Vielzahl von metallischen Mikrostrukturen enthält. Die Gasladekammer ist so aufgebaut, dass sie ein oder mehrere Wasserstoffisotope von der Gasquelle aufnimmt. Das System umfasst auch ein Gasladesystem, das in der Lage ist, einen Gasladedruck an die Gasladekammer zu liefern, die die Mehrzahl von metallischen Mikrostrukturen mit einer Menge von einem oder mehreren Wasserstoffisotopen enthält, um Wasserstoffcluster zu bilden. In einer Form umfasst das System ferner einen Wärmewandler, der einen ersten Teil der Wärmeenergie umwandeln kann. In noch einer anderen Form enthält das System zusätzlich eine Abwärmerückgewinnungsvorrichtung, die einen zweiten Teil der Wärmeenergie aufbringen kann. … Die folgenden experimentellen Beobachtungen sollen die Klarheit und das Verständnis der erfinderischen Aspekte der vorliegenden Anmeldung verbessern und sollen keinen einschränkenden Charakter haben. Es wurden Studien durchgeführt, in denen Wasserstoffisotope ( 1 H, Deuterium (D oder 2 H) und / oder Tritium (T or 3 H)) in Dünnfilmelektroden geladen werden, die ausgewählte Metalle wie Palladium (Pd), Titan (Ti) und Nickel (Ni) enthalten. Diese Untersuchungen zeigen die Erzeugung von Versetzungskernen in dem Metallgitter, die die Bildung von Wasserstoffclustern … fördern können. … 1.
