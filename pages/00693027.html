New proof of Pythagorean Theorem Junyoung Jang Abstract We found a new proof of Pythagorean Theorem by using trigonometry. We induced double angle formula of sine and cosine functions in non-circular way. 1 Deriving double formula of sine and cosine A B C π 2 − α π 2 − α 2α b a a By law of sines [1], b sin 2α = a sin ( π 2 − α) = a cos α . For AC, it holds b = 2 · a cos ( π 2 − α) = 2a sin α. Therefore, 2a sin α sin 2α = a cos α gives sin 2α = 2 sin α cos α. For AB, it holds a = b cos ( π 2 − α) + a cos 2α = b sin α + a cos 2α. Putting b = 2a sin α gives a = 2a sin2 α + a cos 2α ⇒ cos 2α = 1 − 2 sin2 α. 2 Proof of Pythagorean Theorem C A B D θ θ b c ab b + c ac b + c 1 Let AD be a bisector of ̸ BAC. By Angle bisector theorem [2], it holds CD DB = AC AB . Therefore, CD = b c · DB. Since CD + DB = a, we have 1 + b c ! DB = a, i.e. DB = ac b + c , CD = ab b + c . Meanwhile, we have sin 2θ = a c , cos 2θ = b c , tan θ = ab b + c b = a b + c . From cos 2θ = 1 − 2 sin2 θ, we have sin θ = r c − b 2c . From sin 2θ = 2 sin θ cos θ, we have tan θ = sin θ cosθ = 2 sin2 θ sin 2θ = c − b c a c = c − b a . Therefore, a b + c = c − b a , it completes a 2 + b 2 = c 2 .
