Adding Project1World

· archived # 2,432,255
Here is a question from a customer: Q: Can you please add the Project1World Module to my Theater? A: We are no longer adding the Project1World Module into existing Theaters as it is now a Premium Team Module and requires it's own Theater. In order to sign up for Project1World, logout of your website, select the Project1World Module by clicking on "Buy Now" and follow the prompts. Make sure you use a new username! This will set up your new Project1World Theater so that you can begin contributing to the advancement of human consciousness!
