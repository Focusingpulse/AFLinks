τφ-numbers Walter A. Kehowski, PhD, Retd Department of Mathematics Glendale Community College Glendale, AZ 85302 wkehowski @ gmail.com July 11, 2026 Abstract Let τ(n) be the number of divisors of n and let φ(n) denote the number of relatively prime numbers less than n. A number is called refactorable if and only if τ(n) divides n. It is known that φ(n) divides n if and only if n is 3-smooth. Furthermore, n/φ(n) = 2 when n is a power of two and n/φ(n) = 3 otherwise. Define λ(n) = lcm(τ(n), φ(n)). Then n/λ(n) ∈ {1, 2, 3} and n is called a τφ-number. It is the purpose of this note to show when λ(n) = n, called the unital τφ-numbers. 1 The functions τ, φ, and λ Definition 1.1 (τ function [1], [6]).
