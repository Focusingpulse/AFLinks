We say that B ∈ B(H) is a square root of A if B2 = A. We can similarly define a cube root. Indeed, we say that B ∈ B(H) is a cube root of some A ∈ B(H) if B3 = A. More generally, we say that B ∈ B(H) is a nth root of some A ∈ B(H) if Bn = A (where n ∈ N). Example 1.1. Let I be the identity 2 × 2 matrix, i.e. I =  1 0 0 1  . Then I has infinitely many square roots. Indeed, Ax =  x 1 1 − x 2 −x  represents, for each x ∈ R, a square root of I (as A2 x = I whichever x).
