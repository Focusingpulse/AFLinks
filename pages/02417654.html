Kulik September 2026 Abstract An n-bit modular adder is read two ways, and both readings are computed exactly. Theorem A (the reader cut). Present the input positions of (a,b) ↦ a+b mod 2ⁿ in an arbitrary order. The minimal Myhill–Nerode state count after a set S of positions has been read depends only on S — never on the order used to reach it — and factorises over the maximal runs of S: F(S) = PROD over maximal runs [l,r] of S of f(l,r) f(l,r) = 1 if [l,r] = [0,n-1] L = r - l + 1 2 if l = 0 and r < n-1 L+1 if l > 0 and r = n-1 2L+1 if 0 < l <= r < n-1 Memory is a cut functional, not a history functional. Theorem B (the relation residual). Model the same machine as a Cayley complex on ℤ/2ⁿ with generators 2⁰,…,2ⁿ⁻¹, declaring a square whenever its two moves touch disjoint bits. Then b_1^disjoint(n) = C(n,2) + (n-1) = (n-1)(n+2)/2 Both hold for all n. They are different invariants — one a rank, additive over pairs and identical for every reader; the other a state count, multiplicative over the runs of a cut and different for every reading order — and a once-plausible conjecture equating them is refuted structurally rather than numerically. What the two share is a sufficient statistic. On the object side the class of an undeclared square keeps only a seam bit and a carry-run depth; on the reader side a run keeps only a first-nontransparent depth and a carry mode. The exponentially large coordinate label — 2ⁿ basepoints there, 4^|S| assignments here — is in both cases the reader's own coordinates and not the object's structure.
