Chauvet, jerome.chauvet.msc@gmail.com, Nîmes (France) May 27th 2026 Abstract The proof hereafter adresses the Collatz conjecture [1] and relies on the quantitative characterization undergone by the evolving density of even versus odd natural numbers within the limit set produced by infinite iterations of the transformation law T from any initial value taken in IN. This couple of limit densities at infinity for even and odd numbers comes naturally along with respective frequencies of occurence for the two competing transformations of the Collatz system, from which we deduce the final cyclic attractor, hence proving the conjecture. Introduction Although being intensively studied since 1937, the Collatz conjecture has remained unproved until now. It states that the following dynamical system : T ( X n ):={ if Xn is odd, then X n+1=3 X n+1 (*) if Xn is even, then X n+1= X n 2 (**) } must evolve in the limit of the greatest values for n so that : n→+∞ X n=1, X n+1=4, X n+2=2, X n+3=1, ... Despite numerous verifications by direct computation of T that this cyclic attractor must be the only possible end state, no genral proof could be established for any initial value X0∈ℕ until now. Our method Let us remark before all the following : If Xn is odd, then it automatically satisfies the equation X n=2k+1 (k∈ℕ) . In accordance with the definition of T, then we will have the following holding as well : X n+1 =3(2k+1)+1 =6k+4 =2(3k+2) which means that T always produce an even number as an output whenever an odd number is fed to it. However, in case of Xn being even, then X n=2k (k∈ℕ) must then hold, so that, in accordance with the definition of T, we will have now the following : X n+1 = 2k 2 = k which means that whichever Xn we take at random amongst the even naturals as an input to T, the output will have half chance to be odd, half chance to be even, only depending on k.
