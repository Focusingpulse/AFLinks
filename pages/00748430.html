All rights reserved. 1 Introduction In this paper, we define z 0 ≡ z/z for z ∈ C. [1] And, we assume that 00 is exits. Proof Let y = x, then y ′ = x 0 . Here, since the gradient of y is 1 so x 0 = x/x = 1 for ∀x. Therefore, let x = 0, then 00 = 0/0 = 1 so if 0/0 exits, then 0/0 = 1. This completes the proof of the theorem. □ Conclusion Finally, we conclude that For some constant k, if 0/0 = k, then k = 1. Reference [1] ”0의 0제곱”. namu.wiki. Referred definition of z 0 .
