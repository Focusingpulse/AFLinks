Introduction Metric spaces play an important role in the analysis as well as in the applications of mathematics in a variety of fields: fixed point theory and dynamical systems are just a few areas of such applications [5, 7, 9]. This note studies some fundamental properties of the class of hypermetric spaces, which properly contains the class of metric spaces. Let P(R) denote the family of all subsets of R, where R is the set of real numbers equipped with usual metric and R+ = [0, ∞). We recall [2, 8] that a hypermetric space is a pair (X, D), where X is a nonempty set and D is a set-valued map D : X × X → P(R+) such that for all x, y, z in X we have: (a) D(x, y) = {0} if and only if x = y. Examples of hypermetric spaces are provided in [2]. Furthermore, it is shown that every metric space (X, d) induces a hypermetric space (X, Dd).
