Keely Net Mail List: Mirror copying of web sites Mirror copying of web sites Niels =?iso-8859-1?Q?Stenh=F8j?= ( stenhoj@post6.tele.dk ) Sun, 17 Jan 1999 18:57:17 +0100 Messages sorted by: [ date ] [ thread ] [ subject ] [ author ] Previous message: Gerald O'Docharty: "Searl roller simulation" Next message: brent christensen: "static" Hey Keelies: Recently I read about Teleport Pro in a mail from another mail list. This program has the ability of mirror copying a whole web site recreating the same on your hard disk, so that you can browse off-line. I followed an advice to visit the following site: http://www.download.com Then I ran a power scan search for 'browser' and 'off-line'. Then at one of the first search results appeared Teleport Pro and I clicked to download it. I did so by saving the requested site. After installation of it I tested it on http://www.rqm.ch . However, I was a little bit too cautious when I configured this session. I asked Teleport not to include adjoining links, so I missed a few pages that apparently belonged to another department of RQM. Apart from that, it was a success. I found the press release about the 8.3 over unity of the SQM generator in the German branch of the site. I was really amazed by the performance of Teleport Pro. It automatically finds the quickest routes to the requested web site running a number of parallel routes to avoid congestion. The speed exceeded that of my Netscape Smart Update by about 50%. I strongly recommend it. That is the tool we all need when fellow Keelies recommend web sites to be checked.
