The PFT v3.0 uses the main principle of the PFT propulsion for generating a horizontal thrust. The purpose of this mock-up is to study the integration of a PFT thruster in the hull for building a new generation of spacecraft. The vertical thruster has not been yet implemented for separating the effects. The next version of the PFT will uses a Dynamic Vector Potential with a special shaped magnetic field for generating the main vertical thrust.
