PBT Tags: None tachyoncatcher Senior Member Join Date: Jun 2012 Posts: 414 Share Tweet #2 05-25-2013, 01:03 AM power efficiency Hello @Mr. Apol, You can use the same size wire for both coils. The reason, as I understand it, is for the sake of efficiency. The trigger coil will use less power to trigger the transistor if it is smaller. While it does give back, it is not where the "radiant" comes in from. Therefore smaller wire makes sense when trying to build the most efficient device. Some have just used fewer windings for the trigger while using the same gauge wire. Myself, I did as you're proposing and had to use a higher value resistor on the trigger coil for proper timing.
