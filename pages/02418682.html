Basic equations of motion and solutions The linearized equation of motion of an undamped and undriven pendulum is called a harmonic oscillator : (1) d 2 / dt 2 + 0 2 = 0, Nearly all oscillators and oscillations in physics are modeled by this equation of motion, at least in a first approximation, because it can be solved analytically. It is a linear second-order differential equation with constant coefficients. Such a differential equation can be solved easily by the ansatz = exp( t ), where is some constant which has to be calculated. Each d / dt puts a factor before the exponential function. Thus, a linear ordinary differential equation like ( 1 ) turns into a polynomial because the common exponential function (a nonzero factor) can be dropped. Thus, 2 + 0 2 = 0.
