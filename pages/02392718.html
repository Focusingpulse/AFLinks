Орешко Аннотация: Для определения возможности изменения линейных размеров межсоединения с помощью процесса плазмохимического травления было проведено исследование по определению влияния изменения расходов газов на линейные размеры формируемых элементов. Экспериментальные исследования плазмохимического травления оксида кремния проводились на промышленных установках индуктивно-связанной плазмы (inductively coupled plasma), обеспечивающих высокую степень контроля параметров процесса. Процесс плазмохимического травления проводился для газовой смеси, в состав которой вошли: аргон (Ar), кислород (O2 ), октафторциклобутан (C4 F8 ), монооксид углерода (CO). Был измерен эффект при вариации расхода каждого газа в смеси, и на основе этих измерений был подобран режим для уменьшения линейных размеров металлических межсоединений.
