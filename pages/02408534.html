Log in I forgot my password Sympathetic Vibratory Physics &raquo; Hartley Oscillator Page actions PDF Print Share Send link Hartley Oscillator Key Feature: Uses a tapped inductor (or two inductors in series) and one capacitor. How it works: The coil is divided into two parts, and the feedback is taken from the tap point between them. Application: Especially good for low-frequency and medium-frequency sine waves. +V l L1 l + Output l L2 l + ll + C l l Transistor L1 + L2 = resonant coil. C = tank capacitor. Feedback via inductive division.
