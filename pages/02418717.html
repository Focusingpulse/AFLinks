The following steps were taken to recover these ASC files due to an error message generated upon opening them in LTspice involving the first line of characters. Open the ASC file in a binary text editor, such as: EditPad Pro 7 Convert / To Windows (CR LF) Save Close Re-Open it in Windows Notepad Copy all lines after the first line Select some other program which had been previously drawn in LTspice, and... Open it in Windows Notepad Delete all lines after the first line by pasting and overwriting them Save As (and overwrite) onto the ASC file Repeat for each file...;-)
