· archived # 2,442,791
06/21/13 - Removing Skype Home Updates (I had a very annoying problem on Skype where a guy had somehow embedded future updates from him onto my Skype. I looked all over the place for how to get rid of this even though I had deleted him from my contact list. So I finally found this which worked like a charm! I only found one file keyval.db which I deleted and restarted Skype, voila, home page clean! - JWD) For anyone still curious about this issue, theres a forum post already explaining how to take care of the issue. go to appdata > roaming > skype > (your skype username) > and delete any file that starts with keyval . You could also do a search for keyval that might be easier. I deleted the files and it took care of the problem.
