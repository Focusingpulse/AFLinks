IMPORTANT!" Opps.. one more thing - It contains a reverse diode or clamp that is integral and you get it for free. So if you want to pulse a load and then 'disconnect - open circuit it', the diode will clamp any reverse current to ground. For example: Charge up an inductor with the MOSFET, the when the 555 goes low, the MOSFET goes to the high impedance state - except it contains a reverse diode - so the energy stored in the inductor will be shunted to ground. If this did not happen - you would blow any semiconductor with the reverse voltage spike created by the energy in the inductor. If this is what you are trying to do... no semiconductor that I know of could withstand the reverse voltage spike (most overunity type work requires this).
