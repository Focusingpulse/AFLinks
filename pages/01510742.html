All possible combinations of PVC pipe sizes. Schedule 40 has 23 sizes Schedule 80 has 23 sizes which makes each list 2116 rows in length. A big Thank You goes to Aaron for helping me out and placing these files into a zip file and giving that zip file a permanent home. There are two HTML files in one zip file. PVCPipeSizesWithoutCaps.html is the clearance without end caps on the inside pipe. PVCPipeSizesWithCaps.html is the clearance with Schedule 40 end caps on the inside pipe. Each HTML has a Schedule 40 and 80 table at the end of the file. There is no javascript code or supporting css. I didn't restrict the lists to only positive clearances for that would limit it's usage. I know not how the information would be used so I left the table as it was. Remember this posting next time someone is having trouble figuring out what size pipe fit into another. Download zip file here. I hope this can be of use to someone.
