Georg Cantor (1845–1918) Revolutionized mathematics by developing set theory, a foundational framework that underlies much of modern mathematics. His work on infinite sets introduced concepts that were both groundbreaking and deeply controversial during his time. Key Contributions: 1. Set Theory and One-to-One Correspondence: Cantor introduced the idea that two sets have the same cardinality (size) if their elements can be paired in a one-to-one correspondence. This was a crucial insight that led to distinguishing different types of infinity. 2. Transfinite Numbers and Cardinality of Infinite Sets: Cantor showed that not all infinities are equal. He proved that the set of real numbers (the continuum) is strictly larger than the set of natural numbers, demonstrating that there are different "sizes" of infinity. The countable infinity describes the size of the set of natural numbers. The uncountable infinity (continuum) describes the size of the real numbers. Cantor’s diagonal argument proved that the real numbers are uncountably infinite. 3. Hierarchy of Infinities and Cantor’s Theorem: Cantor’s theorem states that for any given set, the set of its subsets (the power set) is strictly larger than the set itself. This leads to an infinite hierarchy of infinities, a concept that was initially met with skepticism. 4. Ordinal Numbers and Well-Ordering Principle: Cantor developed ordinal numbers to describe the order type of well-ordered sets, extending the idea of counting beyond finite numbers. 5. Continuum Hypothesis: Cantor proposed the Continuum Hypothesis, which states that there is no set whose size is strictly between that of the integers and the real numbers. This remains an unresolved question in mathematics - shown by Kurt Godel and Paul Cohen to be independent of the standard axioms of set theory.
