Hi Folks! The other day at work, we setup a CHAT using the free AOL Instant Messenger (AIM) program. This is only available on the new version 2.0 but its free. You can download it at; http://www.aol.com/aim/imreg_download_template?pageset=aol &promo=73010 What makes it special? Well, if you are running AIM, it works like ICQ but has much cleaner screens. Normally you have a list of buddies and the list will show who is currently online so you can chat ONE ON ONE with them. I've been talking with Dan York, Ken Carrigan and a few others at work but only ONE ON ONE. Recently we had need to setup a private chat discussion that only lasted about 2 weeks. This new AIM version 2.0 will allow you to setup a GROUP CHAT with as many people as want to participate and you can save and print the script if goodies turn up in the discussion. The only caveat, everyone has to be running AIM version 2.0 to do the GROUP CHAT, though any version will do the ONE ON ONE CHAT... So, I am upgrading now (it is free) from the above website in the event some of us might want to setup a group chat...if you are using AIM, you might want to get the newest version just in case you might want to use that GROUP CHAT feature...it was pretty slick and easy to setup and remove....just like any chat, you should have some direction and a bit of patience with the free flowing comments..<g>... -- Jerry Wayne Decker / jdecker@keelynet.com http://keelynet.com / "From an Art to a Science" Voice : (214) 324-8741 / FAX : (214) 324-3501 KeelyNet - PO BOX 870716 - Mesquite - Republic of Texas - 75187 Previous message: szymanek@connect.ab.ca: "TOMI" Next message: Adam S.: "Stanley Meyers and his Patents."
