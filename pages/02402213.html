SPAF-2026-main009 CDU: 004.622 An Open Russian-Language Benchmark for Semantic Table Interpretation Kirill V. Tobola1 1 Matrosov Institute for System Dynamics and Control Theory, SB RAS kirilltobola@icc.ru Keywords: semantic table annotation, Column Type Annotation (CTA), Column Property Annotation (CPA), knowledge graphs, Russian-language Natural Language Processing (NLP), tabular benchmarks. Problem Statement Tasks related to the automatic understanding of tabular data [1], specifically Column Type Annotation (CTA) and Column Property Annotation (CPA), which involves identifying semantic relationships between pairs of columns are fundamental for building knowledge graphs and advancing the Semantic Web. Despite the availability of English-language resources such as GitTables [2] and TURL [3], the Russian-language segment of the Internet lacks an open, well-documented benchmark that meets modern reproducibility standards. Existing Russian￾language collections [4] either do not support the CPA task or lack a unified evaluation protocol, making it difficult to compare different methods fairly. Research Goal The goal of this work is to create a standardized Russian-language benchmark for the semantic annotation of tables.
