Database Guidelines For: Additions, Changes, and Your Supportive Input into the data in the INE Database Files. The INE Database of Devices and Inventors is undergoing constant revisions - Based on YOUR INPUT! See the Device Database Template File for submitting and modifying any data. All supportive and constructive information and data are welcome, as well as criticisms with honesty and integrity. Please email any supportive data to: INE Database Input Data To aid in the process of including your input, please note the following: You can submit entries and/or changes using our Device Database Template File . Just copy this file to text, and enter in the proper data in text-only format after the colon for each entry. All of the data is maintained as text in a spreadsheet (Excel) database, using tabs as the column delimiters. Each device is given one row in the database. The text data is stored in the database in consecutive columns, in the order that is seen in any of the Device File listings. Input data received is "transposed" into that order. For printing purposes with long data entries in a data cell, periods and semicolons are used to create new lines when the opportunity arises. The database includes an assessment of the interest level and the commercialization level for each device. These data are determined independently from the information and data given for each device. The exact definitions of these criteria are given below: the Interest Criteria , and the Commercialization Criteria .
