BBS Archived Files &nbsp; You are visitor # since April 24, 1999 . Finally, in 1999, we have all the files posted from the KeelyNet BBS, spanning from 1988 to 1996 when a hard drive crash happened shortly after moving to the Internet. The files are offered in two ways for specificity. Each category is zipped into one file and then all the files are zipped into one 11MB file which unzips to about 30MB. Bear in mind, these files have not been edited and are EXACTLY as posted on the BBS, so clean up is up to you. I prefer using XTreePro to read them as it works quite well. I have the old version 1 which is now public domain so let me know if you'd like a copy and I can email it to you on request. It is a DOS program but I still use it even with Windows 95. One other thing, these files represent a tremendous amount of time and effort over many years of focused attention and networking. If you like what you see or find them of use or value, please consider making a donation to help support KeelyNet and help it grow. Other sites would SELL THEM or piece them out as infopacks which you would pay for. That is against what KeelyNet stands for, that is the free exchange of information so that all may learn from it. For a brief period during the BBS days, people asked for copies of all these files which were sold for $30 up to $50 since it took about 17 disks and a LOT of time to make the copies, that paid for the time and diskettes. In all, I think we sold about 15 sets and gave away a lot more. After much consideration, despite seeing others sell the entire set up to 1994 or selling chunks from it, we have, in the original spirit of KeelyNet, decided that the BBS Archives, from 1988 to 1996 will be offered on the Net for free. If you'd like to support the REAL KeelyNet, please send a few bucks in cash or in a check to; Jerry Decker / KeelyNet, PO BOX 870716, Mesquite, TX 75187 Who knows what we could get done if everyone who uses KeelyNet just sent in $10 per year.
