Directional Structure in the Global Monumental Site Network A Statistical Reframing of the Richat Geodesic Hypothesis Archive

👤 Erydir Ceisiwr · · archived # 2,389,718
Previous work proposed the Richat Structure (21.13 N, 11.40 W) as a geodesic origin point for a predictive framework mapping ancient monumental sites as a polar spoke wheel. Initial Monte Carlo testing (10,000 iterations) supported this framing: Richat-centered bearing clustering was statistically significant against both global-uniform and latitude-matched null models (p = 0.011, latitude-matched). However, an alternative-hub comparison test (5,000 random hub points) revealed that Richat ranks at only the 65th percentile for maximum bearing cluster size, with approximately 43% of arbitrary hub points producing equal or greater clustering for the same site set. This result does not support the claim that Richat is a uniquely privileged geodesic hub. A subsequent inter-site bearing network analysis of all 2,652 directed pairwise bearings among the 52 sites found that the site set itself exhibits statistically significant directional concentration: folded mean resultant length R-bar = 0.711 (p = 0.0004 vs. latitude-matched null, survives Bonferroni correction). Cross-region analysis (R-bar = 0.732) confirms the signal is inter-regional, not inflated by local site proximity. The surviving statistically meaningful result is therefore statistically significant directional structure within the monumental site network, not centrality relative to any single hub. Whether this structure reflects continental-scale geography or a deeper organising principle in monumental placement remains an open question.
