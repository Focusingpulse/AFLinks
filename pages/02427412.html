HELP Overview The HP8112A is a 50MHz Programmbale Pulse Generator capable of generating pulses at defined Periods, Widths, Delays etc., and under different modes of Triggering by External inputs. In this model of Pulse generator we can define the Pulse shapes and Transition times (Both Leading and Trailing edges). The base parameters like Period, Width, Delay and High level can be controlled by an external voltage applied at the Control input. END HELP HELP Using the Panel 5Panels have been defined grouping the parameters based on the functionality and usage. They are MAIN Panel Parameters related to Timings and Trigger modes LEVELS Panel Parameters related to Levels and Output controls OTHER Panel Pulse shape, Transition times and Slope related parameters. STATUS Panel Status and Error displays ABOUT Panel About the Driver Reset Button forces the instrument to the Standard parameter set. Trigger Button simulates the function of MAN key on the instrument. END HELP HELP Main Panel Set Button on this panel duplicates the Key operation of SET on instrument. During the 'Control' selection of Perc, Delc Widc, Hilc the corresponding Parameter settings viz., Period, Delay, Width, Hilevel are not effective on the instrument till the Control mode is changed. When one of the parameters Width/Dcyc are selected the other one is invalidated ( a '?' mark is displayed) indicating the parameter is not active in the output signal. END HELP HELP Levels Panel Amplitude and Offset are only Display compo- nents. They are computed based on Hi_level and Lo_level.
