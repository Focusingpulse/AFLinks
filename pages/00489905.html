Phoenix Numbers Walter A. Kehowski PhD, Retd wkehowski (at) gmail.com March 11, 2026 Abstract If the digits of number n (in base b) can be split p|q so that n = qrpr, where pr and qr are the numbers formed by reversing the digits of p and q, respectively, then n is called a phoenix number in base b. If q has k digits in base b, then n is called a k-Phoenix number in base b. For example, 1.1.n.n is 1-Phoenix in base b = n 2 − 1. The existence of infinitely many k-phoenix numbers in any base b is claimed, but not proven.
