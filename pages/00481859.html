A CONJECTURE ABOUT PRIMES WITH PRIMITIVE ROOT 2 JULIAN BEAUCHAMP Abstract. In this paper, we conjecture that a Collatz-like (“if odd/if even”) function can be used to test whether a prime number has primitive root 2.
