Division by zero Tim Olsson An algebraic theory of extended complex numbers. An extended number is in the form 𝜏 = x∞ⁿ + y where the infinite part ∞ⁿ (n > 0) is a number with the property (±∞)ⁿ × 0ⁿ = (±1)ⁿ (1), and a result of the indivisibility of infinite elements (2) is ƒ(x) = x∞ ⇒ ƒ|ℚ : ℚ → ℤ∞; the sign is located in the dividend*. The theory is noncommutative to keep compatibility with multiplication by zero: x∞ⁿ0ⁿ = x(∞0)ⁿ = x, x ∉ ℚ and is only true with the retention of finite elements; i.e. with multiplication from the right if both sides are raised to the power of 0 as only then Euler's identity holds, this also solves the problem “which y is the solution to y × 0 = x?”: y = x∞, x ∉ ℚ. It is also nondistributive*: ∞ × (0 ± 0) = 1 ≠ ∞ × 0 + ∞ × 0 = 2 ≠ ∞ × 0 − ∞ × 0 = 0; zeros are cancelled out inside parentheses separately. “The Seven Spirits of God”: ∞ − ∞, 0 × ∞, 0 ÷ 0, ∞ ÷ ∞, 0⁰, ∞⁰ and 1 ∞ which equal 1, 1, 1, 1, 1, 1, and e (3). Fallacies are corrected by first multiplying by 0 if also dividing by 0*: 0 × a ÷ 0 = 0 × b ÷ 0 ⇒ (0 × a) ÷ 0 = (0 × b) ÷ 0 = 0 ÷ 0 = 1. *: In this case.
