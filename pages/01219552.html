The first characteristic that this system must possess is that of having a very low ratio between the deterministic component and the random component. Therefore, the random component must overcome the deterministic component. The second characteristic that we need to determine concerns the number of degrees of freedom. This parameter determines how much difficult it is to test hypotheses. This consideration derives from the fundamental problem of statistics defined as follows: "A statistical data does not represent useful information, but becomes useful information only when it is shown that it was not obtained randomly".
