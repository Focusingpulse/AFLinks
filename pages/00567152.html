In details, if n is above two, we hypothesize that the minimal link length of any covering trail, for the above mentioned set of n k points in the Euclidean space R k , is equal to h(n, k) = n k−1 n−1 + c · (n − 3), where c = k − 1 iff h(4, 3) = 23, c = 1 iff h(4, 3) = 22, or even c = 0 iff h(4, 3) = 21.
