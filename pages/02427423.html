Thanks a lot .. Best regards Hello Renaud, As you already know, the manual from Agilent does not include the schematics. According to my manual (which has the schematics), this error code is: The output amplifier is unable to supply a negative offset. Possible faults: Output amplifier A1 Offset DAC A2: U24, U25, U26, U17 Offset latches A2: U21, U22, U23, U43 I've fixed a few of these with this code, and IIRC the problem was an easy one to solve - the -24VDC supply had a problem. If yours is bad, check the following: 1. 2200uF capacitor C4 2. CR2 bridge rectifier 3. U4 voltage regulator 4. Picofuse located in the -24VDC feed. I'm currently posting the complete service manual to alt.binaries.schematics.electronic, it should be there by the time you look. Good luck!
