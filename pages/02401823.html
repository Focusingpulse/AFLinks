GTM2026-main031 Evolutionary Algorithms for Finding Nash Equilibria in a two-side market pricing problem with information distribution on a plane Evgenia Ushakova evushakova@mail.ru The report will discuss the search for Nash equilibrium in the pricing problem in a two-sided market with information dissemination on the plane using an evolutionary strategy. An evolutionary strategy is used to find the Nash equilibrium. Solutions are encoded by vectors whose elements correspond to the players' strategies. The mutation operator makes random changes to the solution components with a given probability. The selection of individuals for the next generation is carried out using greedy strategies based on the players' gains. An experimental study is conducted on test cases with different input data structures.
