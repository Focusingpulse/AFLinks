Дмитриевым Аннотация: Предложен метод расчёта минимально необходимой мощности для «слабого» пользователя в двухпользовательской системе с неортогональным множественным доступом с разделением каналов по мощности (PD-NOMA) с квадратурно-амплитудной модуляцией (QAM), обеспечивающей непревышение заданного порога вероятности символьной ошибки (SER) при известных условиях канала. В большинстве известных методов используется модель Шеннона с идеализированными сигналами и рядом упрощений. Такие модели позволяют оценить теоретический потенциал системы, однако соответствующие методы оказываются неприменимыми в реальных условиях передачи. Для моделей с QAM-созвездиями аналитическое решение задачи отсутствует из-за сложной структуры суперпозиции сигналов и зависимости ошибки от межпользовательской интерференции, вследствие чего широко применяется неоптимальный и вычислительно затратный метод полного перебора.
