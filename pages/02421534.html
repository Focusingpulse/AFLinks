Methods and Apparatus for Enhanced Nuclear Reactions Patent Patentnummer WO2017155520A1 Bezeichnung Methods and Apparatus for Enhanced Nuclear Reactions Anmelder Pinesci Consulting NASA Glenn Research Center Pines, Vladimir Pines, Marianna Steinetz, Bruce Erfinder Pines, Vladimir Pines, Marianna Steinetz, Bruce Chait, Arnon Fralick, Gustave Hendricks, Robert Westmeyer, Paul Anmeldetag 09.03.2016 Veröffentlichungstag 14.09.2017 Erteilungstag 14.09.2017 „ Kernfusionsprozesse in größerer Zahl können realisiert werden, indem energetische Elektronen in einer Umgebung bereitgestellt werden, die ein geeignetes Brenngas, eine Flüssigbrennstoffquelle, eine Festbrennstoffquelle, eine Plasmabrennstoffquelle oder irgendeine Kombination davon enthält. Die Brennstoffquelle kann Deuterium, Tritium, eine Kombination davon oder irgendeine Brennstoffquelle sein, die in der Lage ist, tief abgeschirmte und/oder neutrale Kerne zu erzeugen, wenn sie energetischen Elektronen ausgesetzt werden. Unter geeigneten Bedingungen verschmelzen zumindest einige der tief abgeschirmten und/oder neutralen Kerne mit anderen Kernen. Neutrale Versionen von Deuteron- und/oder Triton-Kernen können erzeugt werden, indem Neutronen mit bestimmten Energieniveaus (z. B. ungefähr 3 MeV, aber optional weniger oder viel weniger als 3 MeV) in Wechselwirkung mit anderen Neutronen gebracht werden, wobei neutrale Versionen von Deuteronen und/oder Tritonen gebildet werden. Solche Prozesse können zum Beispiel zur Stromerzeugung, Wärmeerzeugung, Sanierung von Atommüll, Materialerzeugung und/oder Herstellung von medizinischen Isotopen verwendet werden. “ World Intellectual Property Organization
