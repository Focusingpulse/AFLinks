Computing the Singular Value Decomposition (SVD) with Fixed Point CORDIC Operations with Application to MIMO-OFDM Sasan Ardalan Extra Class Amateur Radio, Ph.D. Abstract In this paper, the computation of the Singular Value Decomposition (SVD) of complex matrices will be presented using xed point arithmetic. The application of CORDIC operations for xed point implementations of the SVD of complex matrices will be introduced. SVD plays a major role in Closed Loop MIMO OFDM systems. The impact of xed point implementation of SVD in a Closed Loop MIMO-OFDM system is ex￾amined. The ratio of Maximum to Minimum Singular Value (MMSVR) is computed for both xed point (CORDIC) and oating point oper￾ations (using the LAPACK library). The xed point implementation closely tracks the oating point results over fading channel models. It is shown that for highly ill-conditioned sub carriers the xed point im￾plementation deviates from the oating point MMSVR. This leads to noise enhancement and degradation of performance. By adding trans￾mit diversity in Closed Loop MIMO-OFDM the MMSVR can be re￾duced and performance substantially enhanced for the xed point im￾plementation. It is also shown how SVD can be used in Open Loop MIMO-OFDM systems.
