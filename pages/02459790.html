Tribal Burial Marker Trees INTRODUCTION Using the phenomenon of dowsing, we have now been able to determine the meaning of Burial Marker Trees as to how many graves they are marking. Further, using the dowsing rods, it is possible to determine the tribal affiliation of the persons buried at the Marker Tree. In general, the configurations of the Burial Trees are very similar for each tribe so there must have been some sharing of the bending techniques. This report will provide pictures of the burial trees for a few tribes we have currently identified and we will add more as we learn about other tribal burial trees.
