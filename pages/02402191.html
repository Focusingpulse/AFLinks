GTM2026-main052 Cooperative Network Games with Changing Communication Structure. Yaroslavna B. Pankratova1 , Leon A. Petrosyan1 1 St Petersburg University yasyap@gmail.com It is supposed that at initial time instant players choose neighbors from given neighbor sets (different for each player) and the number of possible neighbors for different players is different and bounded by prescribed numbers. The communication network is formed after connecting players who choose each other. On the created communication structure the cooperative differential game with prescribed duration is played. The optimal or cooperative network is defined as the network on which the cooperative payoff of players takes its maximal value. Since it was shown earlier that the cooperative network in intermediate time instants may lose its optimality we introduce the possibility of network corrections in some time instants when the game process develops. The value function for described differential network game is defined it its properties investigated.
