Hi, I started this project last year. The plan is to use a set of electromagnets to drive a double bob pendulum, that drives a overrun clutch to a gearbox and flywheel. Once it running than I can drive a PMA with MPPT circuit. This not a OU project. The electromagnets will only be triggered for a short time and power generated will not exceed the power that is available at the output shaft.
